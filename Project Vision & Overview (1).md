# Private Hotline: Asymmetric Direct Communication Network

## Executive Summary
**Private Hotline** (working title) is a bespoke, secure, 1-to-N communication platform designed around a unique **Hub-and-Spoke** concept. Unlike mainstream messaging applications (such as WhatsApp, Telegram, or Signal) where users can discover and interact with anyone on the network, this platform restricts all communication strictly between **one central host (The Owner)** and **invited members (The Clients)**.

For the client, the application acts as an exclusive, direct hotline and emergency safety channel to the Owner. For the Owner, the application serves as a unified command center for managing, communicating with, and tracking all paired contacts.

---

## Core Philosophy & Key Pillars

1. **Absolute Asymmetry:** 
   * **Clients** can only see, chat with, call, and share location with **The Owner**.
   * **The Owner** can see, manage, communicate with, and view maps for **All Clients**.
   * Clients are completely unaware of other users on the platform.

2. **Invitation-Only Access:** 
   * There is no public registration, account search, or global directory.
   * Access is granted exclusively through single-use invitation codes generated by the Owner.

3. **Total Privacy & Zero Metadata Exposure:**
   * All voice, video, text messages, file transfers, and GPS location streams are strictly End-to-End Encrypted (E2EE).
   * Communications flow directly between devices whenever possible, leaving zero trace on intermediate systems.

4. **Safety & Real-Time Awareness:**
   * Built-in continuous live location streaming for safety monitoring, fully encrypted and rendered on open-source maps.

## App Profiles & Experience

The project consists of two distinct application identities operating from the same network backbone:

### 1. App A — The Client App ("The Guest Experience")
* **Purpose:** Built for friends, family, or clients whom the Owner invites.
* **First Launch:** Prompts the user to enter a valid Invitation Code received from the Owner.
* **Main Interface:** Immediately opens into a clean, dedicated communication portal with the Owner.
* **Key Capabilities:**
  * Direct 1-to-1 Text Messaging.
  * Encrypted Voice & Video Calling.
  * Direct Encrypted File & Media Sharing.
  * Continuous E2EE Live Location Sharing (with active system notification).
  * Online / Offline presence status for the Owner.
* **Key Restrictions:**
  * No contact list or search bar.
  * No settings to add other users.
  * No group chat functionality.

---

### 2. App B — The Owner App ("The Hub Experience")
* **Purpose:** Built exclusively for the Owner to manage all incoming and outgoing communications.
* **Main Interface:** A clean dashboard listing all active paired Clients.
* **Key Capabilities:**
  * **Contact Management:** View, organize, or disconnect paired clients.
  * **Invite Generator:** Create custom, single-use invite codes or invitation links.
  * **Multi-Threaded Inbox:** Select any client to open a private 1-to-1 conversation, start a voice/video call, or send files.
  * **Interactive Map View:** View real-time GPS locations, device battery levels, movement speed, and timestamps for clients currently sharing their location.
  * **Access Control:** Instantly revoke a client's access at any time.

## User Journey & Workflow

```
[ Step 1: Owner Generates Code ]
             │
             ▼
[ Step 2: Owner Shares Link/Code with Guest ]
             │
             ▼
[ Step 3: Guest Installs App A & Enters Code ]
             │
             ▼
[ Step 4: Pair Established & Encrypted ]
     ┌───────┴───────┐
     ▼               ▼
 App A (Guest)   App B (Owner)
 (Shows Owner)   (Shows Guest in List & Map)
```

1. **Invitation Creation:**
   * The Owner opens App B, taps "Generate Invitation", and sends the generated code/link to a friend via any external medium (SMS, email, in person).

2. **Onboarding:**
   * The friend downloads App A, opens it, and inputs the code.

3. **Secure Pairing:**
   * The apps exchange security keys automatically in the background.
   * App A permanently binds its view to the Owner.
   * App B receives a notification and adds the new friend to the Owner’s contact list.

4. **Daily Communication & Safety:**
   * Either party can start a chat, initiate an encrypted HD voice/video call, send files directly, or activate continuous live location sharing anytime.
